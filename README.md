# Dynamic Form Project (Flask)

This project is a dynamic form built using Python Flask.  
The form fields are generated dynamically from a JSON configuration file.

---

## Features
- Dynamic form rendering from JSON config
- Conditional field visibility (GST field appears if business is selected)
- Form validation (email, length, required fields)
- Stores submitted data in JSON file
- Simple frontend using HTML, CSS, and JavaScript
